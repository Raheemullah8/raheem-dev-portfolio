# Raheem Ullah - Developer Portfolio

A dynamic, cinematic full-stack developer portfolio built with **Next.js**, **React 19**, **Tailwind CSS**, and interactive canvas scrubbing animations.

## 🚀 Features
- **Scrubbing Canvas Engine:** High-performance canvas-based frame rendering synced with scroll progress.
- **Enterprise FBR Showcase:** Dedicated section highlighting real-world experience at **Innovative Network Pvt Ltd** building FBR tax-compliant digital e-invoicing pipelines and template customization.
- **Agentic AI Track:** Showcasing ongoing enrollment and learning at **Saylani Mass IT Training (SMIT)**.
- **Mobile Responsive Navigation:** Sleek hamburger drawer toggle navigation for mobile screens with seamless section jumping.
- **Live GitHub Activity:** Integrated GitHub stats, top languages, streak tracking, and contribution grid snake animations.
- **Direct Connect Hub:** Instant WhatsApp, email copy, and social links.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, Glassmorphism, Custom Glow System
- **Icons:** Lucide React & Brand SVGs
- **Deployment:** Vercel

## 💻 Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
